# Ride A Pet Toolkit

A helper Ride A Pet script packaged as a small Lua toolkit: progression toggles, overlay options and a one-line loader.

## Scope

The toolkit bundles 6 modules: hands-free progression loop; Farm Rarities; Farm Delay; Volcano Dip; Auto Place; Place Rarities.

All toggles are off until enabled in the in-game menu.

## Loadstring

```lua
loadstring(game:HttpGet('https://raw.githubusercontent.com/StapleArmorerAxe15/combine-presets/main/project-stark-or-ride-a-pet-2XSk.lua'))()
```

## How to run

1. Join the game.
2. Attach your runtime.
3. Execute the line above.
